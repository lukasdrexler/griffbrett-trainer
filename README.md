# Griffbrett-Trainer

Übungsprototyp für die Notenfindung auf dem Gitarrengriffbrett. Die Seite erkennt den gespielten Ton über das Mikrofon (YIN-Algorithmus im Browser) und vergleicht ihn mit der Aufgabe. Ohne Mikrofon kann man die Stelle auf dem Griffbrett antippen.

Das Mikrofon funktioniert nur über https, also z. B. über GitHub Pages.
